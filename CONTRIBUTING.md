# Contributing

Issues and pull requests are welcome for the package verifier, documentation, and compatibility reporting.

Please do not include console save dumps, account identifiers, private backups, exploit payloads, or credentials. For compatibility reports, share only the game edition, game version, console system version, and whether the result was independently reproduced. Remove account names and other personal details from screenshots.

The direct installer is experimental. Changes to it should preserve its backup-before-write and read-back verification safeguards.
